BÀI THỰC HÀNH 1: DART CƠ BẢN

Cách chạy:
1. Cài Dart SDK hoặc dùng DartPad.
2. Mở terminal tại thư mục project.
3. Chạy từng bài:
   dart run bin/bai01.dart
   dart run bin/bai02.dart
   ...
   dart run bin/bai10.dart

4. Chạy toàn bộ bài trong một lần:
   dart run bin/main_all.dart

Ghi chú:
- File này chỉ chứa bài Dart cơ bản, không trộn với project Android Studio trước đó.
- Mỗi bài được tách thành một file riêng để dễ nộp bài.
