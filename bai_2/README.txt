HUONG DAN MO PROJECT

1. Giai nen file Android_UI_BaiTap.zip.
2. Mo Android Studio.
3. Chon Open, sau do chon thu muc Android_UI_BaiTap.
4. Cho Android Studio Sync Gradle.
5. Chay app tren may ao hoac dien thoai Android.

Project gom 5 bai:
- Bai 1: LinearLayout - Thong tin ca nhan
- Bai 2: ConstraintLayout - Form dang nhap
- Bai 3: ScrollView + CardView - Danh sach mon hoc
- Bai 4: Fragment - Profile co tab
- Bai 5: Mini Project UI - Quan ly lop hoc

Package: com.example.androiduibaitap
