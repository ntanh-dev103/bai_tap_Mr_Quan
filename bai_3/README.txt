PROJECT: DanhSach_ListView_RecyclerView_Java
Ngon ngu: Java
Noi dung: Bai thuc hanh hien thi danh sach voi ListView va RecyclerView

Bao gom:
1. Bai RecyclerView san pham
   - ProductRecyclerActivity.java
   - Product.java
   - ProductAdapter.java
   - activity_product_recycler.xml
   - item_product.xml
   - Du lieu san pham luu trong ArrayList<Product>
   - Moi item co ten san pham, gia san pham, mo ta ngan
   - Nhan vao san pham se hien Toast ten san pham duoc chon
   - Dung RecyclerView, Adapter, ViewHolder, LinearLayoutManager

2. Bai ListView mon hoc
   - SubjectListViewActivity.java
   - activity_subject_listview.xml
   - Co o nhap ten mon hoc
   - Co nut Them mon hoc
   - Co nut Xoa tat ca
   - Co ListView hien thi danh sach mon hoc
   - Nhan vao mon hoc se hien Toast mon hoc duoc chon

Cach mo project:
1. Giai nen file zip.
2. Mo Android Studio.
3. Chon File > Open.
4. Chon thu muc DanhSach_ListView_RecyclerView_Java.
5. Doi Gradle Sync xong.
6. Bam Run.

Luu y:
- Project nay doc lap, khong tron voi cac file Android va Dart truoc do.
- Project su dung Java va XML.
- Project da bat AndroidX trong gradle.properties.
